# Security policy

`script-inspector` reads package manifests and checks file metadata. It does not execute analyzed scripts or invoke a shell.

## Reporting a vulnerability

Please do not post an unpatched vulnerability or sensitive proof of concept in a public issue. Use GitHub's private vulnerability reporting for this repository when it is available. If private reporting is unavailable, contact the maintainer through the [GitHub profile](https://github.com/azmolwasimhussain-ops) and share only the information needed to investigate privately.

Include the affected version or commit, the steps needed to reproduce the issue, and its likely impact. Do not include real secrets or another person's data.

## Supported versions

Before the first NPM release, the `main` branch is the supported development version. Once releases are published, this policy will be updated with supported release versions.
